# 🏙️ Urban Haven Apartment Website

**Urban Haven** is a modern, responsive website built with HTML and CSS to showcase rental apartments. It highlights different room options, pricing, and amenities in a clean, user-friendly layout.

## 📌 Project Overview

Urban Haven is a fictional apartment rental platform designed to provide prospective tenants with a visual overview of available housing options — including single rooms, bedsitters, and multi-bedroom units. Each listing comes with detailed pricing and a list of key amenities.

## 🧱 Built With

- **HTML5** – for semantic, structured content
- **CSS3** – for responsive and modern styling

## 💡 Features

- 🧭 **Header Navigation** – Clean and easy-to-navigate header section.
- 🏠 **Room Listings** – Multiple housing types with prices and photos.
- 📋 **Amenities Section** – Detailed features for each room or apartment.
- 📱 **Responsive Design** – Works well on desktops, tablets, and mobile devices.

## 🖼️ Sections Overview

- **Header** – Site logo and navigation menu.
- **Hero / Intro** – A welcoming section for new users.
- **Room Types** – Grid or card layout displaying all available apartments.
- **Amenities** – Icons or lists showing included features like Wi-Fi, water, parking, etc.
- **Pricing** – Transparent pricing info per room type.
